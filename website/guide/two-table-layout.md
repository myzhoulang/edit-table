# 两表布局

头表包含 thead 与固定对比行 tbody，主体表承载行窗口。两表从同一列宽数组生成 colgroup，使用固定表格布局，边框只画右侧与底部。分区方式参考 Ant Design Table。

横向滚动使用独立的原生滚动条；正文只原生纵向滚动，横向溢出被裁剪。横向滚动条的 scroll 回调在同一次样式提交中移动头表、主体表，并抵消固定格位移。固定列不会先随浏览器横滚再回位，因此拖动滑块与惯性滚动都不依赖回调及时赶上合成器。

横向滚轮及 Shift+滚轮更新独立滚动条，斜向手势同时更新正文纵向位置；纯纵向与缩放手势沿用浏览器原生行为。程序定位、键盘导航与拖选自动滚动使用同一组横向坐标。合并层、选区层按左 / 中 / 右分段裁剪，固定覆盖层直接使用视口横坐标。头区 clientWidth 补偿纵向滚动条。

合并层使用正文坐标，垂直方向由浏览器随表体一起滚动；文字固定居中于整个合并格。选区层继续按视口坐标绘制。

M0 原型在 spikes/two-table，三引擎、DPR 1/2、五种 CSS 缩放已验证；CSS 缩放与浏览器工具栏缩放的边界见 [性能页](/performance)。
