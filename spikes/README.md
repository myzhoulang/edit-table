# 两表布局技术验证

运行 `bun run dev`，访问 `/spikes/two-table/`；自动化运行 `bun run test:spike`。

原型与正式源码独立，数据规模 100,000 × 12。固定行位于头表 tbody；主体为唯一滚动源，固定列由根 CSS 变量补偿；合并块内容依据视口交集定位。

自动化覆盖三种浏览器引擎、DPR 1/2、CSS 缩放 80/100/125/150/200%。CSS 缩放用来增加亚像素覆盖，不等同于浏览器工具栏缩放。

人工补充：在正式 Chrome、Safari、Firefox 中分别用触控板、滚动条和键盘滚动；使用浏览器工具栏更改缩放；弹出编辑器后滚动与改变窗口；记录原 sticky 问题的复现条件。
