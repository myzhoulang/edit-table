# 固定对比行

rowPinning: true 默认容量 1，或 { maxRows: 3 }。超过容量先进先出，重复固定不操作。固定行位于头表，复用列宽、显隐、横向滚动和固定列。

内容来自视图文本，原行在虚拟窗口之外仍可显示。render 列用 pinnedText 提供纯文本。固定区只读，不进入选区、剪贴板或历史。

整列选择时，固定副本中的同列延续视觉边框和淡色底；管理栏只延续两侧边线，按钮与勾选保持可用。此效果不改变 SelectionSnapshot，也不会将固定副本重复复制或编辑。

固定区行号旁常显 × 取消按钮，点击行号定位并仅选择原行；关闭行号时操作保留在首列。管理栏显示固定数量，支持勾选一个或多个固定行后「取消选中固定」，也可「取消全部固定」。这些入口不随横向滚动移出视口。

正文中已固定行的行号前显示蓝色标记。固定副本沿用源逻辑行号，不额外占号；派生行同样可以固定和取消。行号宽度根据总逻辑行数调整。

源行修改同步刷新，身份消失自动取消。pinnedDiff 为活动行标记与首个对比行的文本差异。
