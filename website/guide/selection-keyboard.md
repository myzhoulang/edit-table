# 选区与键盘

点击单格、矩形拖选、Shift 扩选、Ctrl/Cmd 多区域，单元格选择会递归扩展合并范围。点击表头选真实记录列段，边缘自动滚动。

点击表头时，SelectionSnapshot.mode 为 column，整列与表头高亮。active 保留首个可选单元格作为键盘导航起点，不表示额外选中该行：行号不高亮，也不会由此默认固定或取消固定第一行。

点击行号仅选择当前逻辑行，拖动行号或 Shift 连选多行，Ctrl/Cmd 添加多行选区；纵向分类合并不会扩大行选择。SelectionSnapshot.mode 为 row 时表示此方式，普通单元格选择省略 mode。scrollToRow 的 select: true 使用同样的行选择语义。

整行选框包含行号，跨固定列边界连续绘制；选中行的行号使用主题色底和白字。

点击表格外部会清除全部选区、活动单元格和行号高亮；工具栏、菜单、日历及下拉编辑浮层属于表格内部，操作它们时保留选区。

真实记录与可见派生行从 1 连续编号；隐藏的派生行不占号，固定副本不占新号。行号是视图位置，不是 sourceIndex 或稳定身份。行选择清空、剪切或单值填充时，未被完整选中的纵向合并格会跳过，避免改动其他记录的分类。

| 按键                     | 行为                      |
| ------------------------ | ------------------------- |
| 方向 / Shift+方向        | 导航 / 扩选               |
| Ctrl/Cmd+方向            | 当前区块边缘              |
| Home / End               | 行首 / 行尾               |
| PageUp / PageDown        | 按视口翻页                |
| Enter / Shift+Enter      | 下移 / 上移，编辑时先提交 |
| F2 / 双击                | 编辑原值，光标从末尾开始  |
| Tab / Shift+Tab          | 左右移动，跨行            |
| Delete                   | 清空可写格                |
| Backspace                | 空白草稿，Esc 可取消      |
| Ctrl/Cmd+A               | 全选                      |
| Ctrl/Cmd+Z / Y / Shift+Z | 撤销 / 重做               |

固定行不参与导航；navigable: false 的列跳过。

## 相关 API

Alt+F10 聚焦图标工具栏，可用 Tab 在按钮间移动；工具栏与菜单的原生键盘事件不会触发表格编辑。Escape 关闭菜单并回到表格。
