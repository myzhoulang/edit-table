# 行虚拟化

默认 threshold 200，overscan 8；用 spacer 行保持总高度，窗口节点通过池复用。编辑行可作为额外窗口段保留。

行度量采用固定估算与块级 Fenwick 索引。rowHeight: auto 测量已渲染行，未测量行用密度估值。合并块内容固定在整个合并单元格中央，随单元格自然滚动；长合并格的文字可能滚出视口，不会按可见范围重新居中。

合并层与正文共用预渲染窗口，提前绘制即将进入视口的合并格；非虚拟表格一次绘制全部合并格。滚动时复用合并单元格、文字和裁剪分区，不逐帧改写文字位移或高度，避免重复定位导致跳动；离开预渲染窗口的合并格及时回收。

增删行按源变化与派生行边界拼接受影响的逻辑行段，复用未变化的布局跨度和表头；其余行只调整坐标。高度索引仅重建边界块和块索引，保留其他行已测量的高度。视口上方增删行时按稳定身份保持滚动锚点。

配置、列宽或列显隐改变时重新构造布局。业务 visible 函数使共同前后段不再一致时安全回退到完整投影。拼接不意味着整个事务为常数时间：记录数组、身份索引和跨行计算仍可能随行数增长。

画布安全高度为 16,000,000 px，超过时报告错误；性能数字和验证边界见 [性能报告](/performance)。
