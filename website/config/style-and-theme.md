# 外观

CSS 变量：--edit-table-bg、-text、-border、-header-bg、-header-text、-stripe-bg、-hover-bg、-selected-bg、-active-color、-error-color、-derived-bg、-pinned-bg、-locked-bg、-row-height、-font-size。

样式允许 color / background / backgroundColor / fontFamily / fontSize / fontWeight / fontStyle / lineHeight / textDecoration / textAlign / whiteSpace / wordBreak / overflowWrap / padding 和业务 CSS 变量。禁用 et-_、edit-table 保留类名与 --edit-table-_ 变量，分别返回 reserved-class / invalid-style。
